# Pricing platform follow-up

This repository presents AkiliBiz marketing pricing and routes plan or trial interest to the contact flow. It does not create subscriptions, provision trials, process payments, or enforce plan limits.

Actual plan enforcement must be implemented separately in the AkiliBiz platform/backend repository. That work should define the canonical plan catalogue, subscription and trial lifecycle, business entitlements and limits, billing-provider integration, and server-side feature enforcement before any self-service checkout or automated trial claim is introduced here.
